## Lossless Extraction, Explained

The detail that sets file juicer for mac apart is that it does not touch the data it recovers. When it
finds a picture inside a PDF or a sound clip inside a document, it writes that item out byte-for-byte in
its original format wherever possible. Nothing is downscaled, transcoded or flattened, so an extracted JPEG
is the same JPEG the file was carrying. For anyone who needs to extract images mac at full quality — for
archiving, reuse or evidence — that faithfulness matters more than any conversion feature would.
